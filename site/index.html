CUDA Course

GPUs and CUDA for Parallel Computing

A practical course site for understanding heterogeneous computing, writing first CUDA kernels, reasoning about GPU architecture, and tuning memory-bound workloads for real performance gains.

Modules

The syllabus follows the local course outline and turns the PDF plus curated resources into a teachable sequence.

  • M1Introduction to Heterogeneous Parallel ComputingWhy GPUs exist, what they accelerate, and where parallel thinking starts to matter.
  • M2CUDA Programming ModelHost code, kernels, grids, blocks, memory allocation, and a first vector-add kernel.
  • M3GPU Compute ArchitectureSMs, warps, scheduling, divergence, latency hiding, and occupancy.
  • M4Memory Architecture and Data LocalityMemory spaces, bandwidth limits, tiling, matrix multiplication, and boundary handling.
  • M5Performance MeasurementCPU timers, CUDA events, bottleneck analysis, and reliable measurement workflow.
  • M6Memory OptimizationPinned memory, asynchronous copies, streams, and reducing global-memory pressure.
  • M7CUDA Configuration OptimizationThread-block sizing, resource trade-offs, and systematic kernel tuning.
  • M8CUDA and PyTorchUsing `torch.cuda` to move tensors and models onto GPU and reason about runtime behavior.

Learning outputs

  • Understand the CPU/GPU split in heterogeneous systems.
  • Write and launch simple CUDA kernels.
  • Reason about warps, divergence, occupancy, and memory bandwidth.
  • Measure runtime correctly and identify where time is actually spent.
  • Apply first-line optimization techniques in CUDA and PyTorch workflows.

Course direction

The sequence begins with the fundamentals from heterogeneous data-parallel computing, then moves into execution, architecture, memory, measurement, and optimization. The final module shifts the same ideas into PyTorch so the GPU model remains actionable in everyday ML code.

The site is authored in English to preserve technical precision. Italian is available through the on-page language selector.
